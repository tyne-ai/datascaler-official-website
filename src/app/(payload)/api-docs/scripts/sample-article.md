## 为什么声量不等于信任

在消费品类里,同一场讨论既能带来需求,也常常藏着**最早的犹豫**。社媒聆听的难点不在“听见”,而在于把喧嚣和真正的购买信心分开。

## 四类信号

我们把购买信心拆成四个可读的信号:

- 产品信号:功能、质量、真实使用体验
- 拥有信号:开箱、复购、长期使用反馈
- 价值信号:价格、性价比、替代品对比
- 信息信号:用户还缺哪些决策信息

### 怎么用

1. 先按信号给讨论打标签
2. 再看每类信号的正负比
3. 最后把结论**溯源回原帖**,让每一条都能点回证据

> 每条结论都能点回原帖,才是可以带进决策会议的洞察。
